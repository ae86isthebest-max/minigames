# 開心農場鋪 — 大擴充（2026-11-15，使用者要求）

使用者原話重點：
- 擴大咗超級市場之後，應該可以起第二個牛棚、多幾部果汁機等等，「想去大少少」。
- 貨架上限太少（雞蛋最多二十幾個），要再多。
- 要多啲種類，超級市場應該有多啲嘢賣。
- 開咖啡館（第二個地圖）嘅門檻調高；之後嘅地圖全部都要。
- 第一個地圖太快玩完，要長好多，大約而家嘅 **5–6 倍**。全部地圖都照做。

## 每個地圖都要做嘅五樣嘢

### 1. 擴建區（新土地）
- 地圖上加一個「擴建：XX區」嘅大虛線框（大約喺第一排新產品之前），買咗之後拆走一邊嘅圍欄／樹，開出一大塊新地（大約同而家農地一樣大）。
- 新產品線同第二套生產設施都放喺新地，唔好逼喺原本地方。
- 導航網格同玩家可行範圍要跟住擴大；新地要有路接返主路。

### 2. 第二套生產設施（擴大之後先開）
- 每種動物棚／主要機器都可以起第二個，例如農場：第二牛棚、第二果汁機、第二起司坊、第二麵包窯、第二磨豆漿機、第三雞舍。
- 佢哋同第一個一樣有「+1」同「做更快」框，員工會自動照顧。

### 3. 容量加大
- 貨架容量升級加到 40（貨架上要真係睇到 40 件，可以疊高）。
- 新升級「存貨量」：動物棚同機器嘅出貨盤／入貨盤上限由 12 加到 30，分 4–5 級。
- 倉庫容量 200 → 可升級到 600。

### 4. 新貨品（每個地圖加 4–5 條新產品線，全部要有 3D 模型同顏色）
- 每條線 = 田／動物（或採集點）＋ 貨架；其中 2–3 條再加一部加工機器同加工品貨架。
- 每樣新產品都有自己嘅 +1 成長框、做更快框、清楚嘅 desc。
- 新貨架同樣可以喺百貨公司第二排再起一個。
- 建議主題（可以按地圖再調）：
  - 農場：草莓園→草莓、草莓→果醬機→果醬；紅蘿蔔田；南瓜田→（第二麵包窯）南瓜派；羊圈（食草）→羊毛→毛線機→毛線球；蜂箱（需要花田）→蜂蜜。
  - 咖啡館：茶園→茶葉→紅茶機→紅茶；抹茶田→抹茶粉；草莓→草莓蛋糕；鬆餅機；可可→巧克力。
  - 漁港：蠔田→蠔；龍蝦籠→龍蝦；海膽；魚丸機（魚→魚丸）；煙燻爐（魚→煙燻魚）。
  - 森林：竹林→竹→竹器工坊；藍莓叢→藍莓→果醬；栗子樹→炒栗子機；鹿／蜂場延伸。

### 5. 遊戲時間 ×5–6
- 新內容本身增加大約 25–35 個新解鎖步驟。
- 由「小狗／第一個理貨員」之後嘅建築、升級、+1 價錢整體 ×2.5–3；新內容價錢由幾千起，最尾一批去到十幾萬至幾十萬。
- 開分店門檻（去下一個地圖）大幅調高：
  - 農場 → 咖啡館：總收入 40,000 → **400,000**，費用 15,000 → **150,000**，而且要先起好擴建區＋至少 3 條新產品線。
  - 咖啡館 → 漁港：總收入 120,000 → **1,200,000**，費用 60,000 → **500,000**。
  - 漁港 → 森林：總收入 150,000 → **1,500,000**，費用 120,000 → **600,000**。
- 每條新內容要靠前面賺到嘅錢先買得起：保持「每 5–6 次購買就有一樣新嘢」嘅節奏，唔好有長時間乜都買唔到。
- 舊存檔：價錢變咗冇所謂，已經起咗嘅嘢保留；已經開咗嘅地圖保持開咗。

## 共通規則
- 遊戲入面文字：台灣繁體中文。
- 卡通低多邊形風格，K.mesh 圓角零件、自動黑邊、K.bakeStatic；顏色鮮艷。
- 唔好逼：新嘢唔可以阻住路、門口、客人路線；虛線框唔可以重疊。
- 測試：起晒所有嘢模擬幾分鐘，冇人穿牆（0 或接近 0）、冇錯誤、冇客人卡住；舊存檔載入正常；截圖自己睇過。
